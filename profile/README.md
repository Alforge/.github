# Alforge

Infrastructure for working with AI coding agents.

Alforge is where the agentic-software plumbing lives. The premise is that the
hard part of coding agents is not the model or the prompt — it is the
operations around them: giving every task an isolated, reproducible
environment; keeping humans in the loop through ordinary pull requests; and
making agent work observable, cancellable, and accountable.

The systems here run coding agents as first-class contributors against real
repositories, with Git and GitHub as the source of truth — small, legible,
self-hosted pieces rather than another opaque platform.
