# Alforge

Internal tooling for running and operating AI coding agents.

- **[ai-dispatcher](https://github.com/Alforge/ai-dispatcher)** — issue-backed
  coding control plane. Runs OpenCode sessions in isolated git worktrees, one
  branch per GitHub issue.
- **[command-center](https://github.com/Alforge/command-center)** — read-only
  service management and status.

Contributions follow the organization-wide [contributing
guide](https://github.com/Alforge/.github/blob/main/CONTRIBUTING.md).
